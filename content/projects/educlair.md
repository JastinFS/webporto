Platform e-learning teknologi bergaya produk modern — landing publik, katalog kursus, learning path, halaman instruktur, pricing, blog, plus **area login** dengan dashboard student dan panel admin.

- **Katalog kursus**: pencarian, filter kategori & level, sorting, dan halaman detail per kursus (durasi, jumlah lesson, rating, instruktur, harga + diskon, "what you'll learn", enroll / Pro).
- **Learning Paths** — rangkaian kursus tersusun menuju sebuah role (Full-Stack Developer, Data Analyst, ML Engineer, Cybersecurity Specialist) dengan estimasi durasi & outcome.
- **Student dashboard** (route ter-proteksi): overview progres, "continue learning", streak & weekly goal, halaman **Progress** (grafik waktu belajar + skill proficiency), **Certificates** (kredensial + verify + PDF), dan **lesson player** dengan kurikulum sidebar, video, catatan, dan resource.
- **Admin panel**: platform overview, **Analytics** (revenue trend, enrollments by category), **Course/User/Order management** — order lintas provider pembayaran (Stripe · Midtrans · Xendit).
- Autentikasi dengan role (student / instructor / admin) + session security.
- Dibangun dengan **Next.js App Router + React Server Components**, TypeScript, Tailwind CSS; bundling via Turbopack. Konsep "learn by building" — tiap kursus menghasilkan artefak nyata.
