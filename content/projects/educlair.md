Platform e-learning teknologi bergaya produk modern — landing, katalog kursus, learning path, halaman instruktur, pricing, blog, dan **dashboard belajar** yang terlindungi autentikasi.

- **Katalog kursus** dengan pencarian, filter kategori & level, sorting, serta halaman detail per kursus (durasi, jumlah lesson, rating, instruktur, harga + diskon, "what you'll learn", enroll / Pro).
- **Learning Paths** — rangkaian kursus tersusun menuju sebuah role (Full-Stack Developer, Data Analyst, ML Engineer, Cybersecurity Specialist) lengkap dengan estimasi durasi & outcome.
- **Dashboard** (route ter-proteksi, redirect ke login): progress per kursus, streak harian, weekly goal, aktivitas terbaru, dan "continue learning".
- Halaman **Instructors**, **Pricing**, **Blog**, **About / Contact**, plus alur **Sign in / Register** dengan session security.
- Dibangun dengan **Next.js App Router + React Server Components**, TypeScript, dan Tailwind CSS; bundling via Turbopack. Konsep: "learn by building" — tiap kursus menghasilkan artefak nyata, bukan sekadar catatan.
