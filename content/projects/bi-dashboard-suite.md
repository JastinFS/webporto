Kumpulan dashboard BI multi-gaya untuk visualisasi data bisnis.

- Dashboard sales bergaya **Tableau** — regional heat map, category breakdown, profit analysis.
- Dashboard eksekutif bergaya **Power BI** — KPI scorecard, revenue forecasting, customer segmentation.
- **BIStream v2**: platform self-service analytics — upload CSV/Excel, live API data, cross-chart filtering, drag-and-drop layout, dark mode, dan export PDF.
